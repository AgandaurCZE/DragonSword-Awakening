Introduction

Quick info

The in-game codex shows max-level values only. Lower levels use multipliers measured in-game: Lv. 1 = max ÷ 1.75, then ×1.05, ×1.10, ×1.15, ×1.23, ×1.30, ×1.38, ×1.48, ×1.58 at Lv. 2–9 for level-10 skills (×1.10, ×1.20, ×1.33, ×1.45, ×1.60 at Lv. 2–6 for level-7 skills). Values can be 1% off the game’s because of rounding. Only the “Attack Power % Damage” values change; stacks, durations, buffs and heals are shown as recorded.
